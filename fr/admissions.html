Inscription

Dites-nous qui vous êtes et quel cours vous intéresse. Le formulaire ouvre WhatsApp avec votre message prêt à envoyer.

Inscription

  1. Remplissez le formulaire et appuyez sur le bouton : WhatsApp s'ouvre avec votre message.
  2. Envoyez le message. Le service des inscriptions répond et confirme le cours, la langue, les frais et la date de début.
  3. Pour l'anglais pastoral ou l'anglais oral, vous faites d'abord un enregistrement de placement d'une minute.
  4. Vous recevez votre première leçon sur WhatsApp.

Cours

Votre message est prêt. Si WhatsApp ne s’ouvre pas, utilisez le bouton ci-dessous. Vérifiez vos informations et appuyez sur Envoyer dans WhatsApp pour terminer votre demande.

Continuer sur WhatsApp

Rien n'est enregistré sur ce site : vos informations vont seulement dans le message WhatsApp que vous choisissez d'envoyer.
